# Fuentes Editables del Storyboard — MaskDude

Este directorio preserva los archivos vectoriales y multicapa correspondientes al guion gráfico maquetado en [`04_storyboard.pdf`](../04_storyboard.pdf).

## Archivos Disponibles

1. **`fuentes_del_storyboard.svg`**:
   - Diagrama vectorial completo en resolución $1920 \times 1080$ con las 6 viñetas (V01 a V06) en proporción panorámica 16:9.
   - Compatible para edición multicapa con **Krita**, **Inkscape** o **Adobe Illustrator**.
   - Incluye guías de composición, bloques de metadatos técnicos, estados de control (`State.LOCKED` vs `Control Pleno`) y códigos de color dramáticos.

## Instrucciones de Edición y Actualización

1. **Apertura:** Abrir `fuentes_del_storyboard.svg` en Krita como documento con capas vectoriales.
2. **Dibujo o Sustitución de Bocetos:** En la capa correspondiente a cada recuadro (`V01` a `V06`), incorporar los trazos en pixel art, capturas anotadas del prototipo o bocetos manuales.
3. **Exportación:** Toda modificación debe exportarse manteniendo la resolución de 150 DPI y sincronizarse con el documento oficial [`04_storyboard.pdf`](../04_storyboard.pdf).
